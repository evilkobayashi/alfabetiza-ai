# 🎙️ Alfabetiza AÍ

### A primeira Inteligência Artificial de alfabetização com interface 100% conversacional (Voice-First)

</div>

O **Alfabetiza AÍ** quebra a principal barreira da educação digital: *exigir que o usuário saiba ler para conseguir navegar no aplicativo*. Com uma arquitetura sem interface gráfica complexa, o aluno utiliza apenas a voz para aprender a ler e escrever, sendo guiado por um tutor de IA hiper-paciente.

---

## 🚀 Diferenciais (Nível AAA)

- **Voice-First UI:** Sem menus complexos. O aluno aperta um botão, fala o que não entendeu (Speech-To-Text) e a IA responde em áudio (Text-To-Speech).
- **Latência Ultrabaixa (Edge):** Integração com a rede neural Whisper-Large-V3-Turbo (via Groq) para transcrição instantânea sem *delay*.
- **Perfis Adaptativos:** O LLM adapta o tom de voz e os exemplos instantaneamente. O adulto da EJA é tratado com respeito (sem infantilização), a criança no KIDS é tratada com paciência, e há suporte para PCD.
- **Orquestração Desacoplada:** Backend puramente em FastAPI isolando a lógica da IA, enquanto o frontend em Next.js lida com a captura nativa de áudio.

## 🛠️ Stack Tecnológico

- **Frontend:** Next.js 15, React 19, TailwindCSS, Clerk Auth (PWA-ready).
- **Backend:** Python, FastAPI, Integração Multimodal.
- **IA Pipeline:** Groq (Whisper STT) ➡️ Google Gemini Flash (Raciocínio Pedagógico) ➡️ Edge TTS (Voz Neural).
- **Infraestrutura:** Vercel (Frontend) + Railway (Backend) + PostgreSQL.

## 🔗 Ecossistema
Faz parte da suíte **AÍ Tecnologia e Educação**, integrando-se estrategicamente para cobrir toda a jornada escolar pública e privada.
